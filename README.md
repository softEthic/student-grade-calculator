# Student Grade Calculator

A simple Java console application that calculates student grades and provides a summary of the results.

## Features

* Enter multiple grades
* Validate grades between 0 and 100
* Calculate the average grade
* Determine the letter grade
* Determine pass or fail
* Find the highest grade
* Find the lowest grade
* Calculate another set of grades without restarting the program

## Technologies Used

* Java
* Scanner
* Arrays
* Loops
* Conditional statements
* Input validation

## How to Run

1. Clone the repository.
2. Open the project in a Java-compatible IDE or VS Code.
3. Compile the program:

```bash
javac GradeCalculator.java
```

4. Run the program:

```bash
java GradeCalculator
```
